# Research — entry rationale

## The fixed text

The entry is exactly `ekilingkey-coder`, the entrant's own make.fun handle.

- Characters (Unicode code points): 16
- UTF-8 bytes: 16 (all characters are ASCII)
- Whitespace characters: 0 — one whitespace-delimited token, no spaces, no padding
- Gate check: 1..30 characters, not whitespace-only — **pass**
- Note on the brief: it states "15 characters". Counting the literal string gives 16
  (10 letters `ekilingkey` + 1 hyphen + 5 letters `coder`). The gate allows 1..30, so
  the entry is valid; the exact handle text is kept and no character is dropped to
  match the miscount. `entry.txt` is stored as those 16 bytes with no trailing newline.

## Why it works as a name

At a glance `ekilingkey` splits into `e` + `kiling` + `key`: the middle `kiling`
reads like "killing", so the front half suggests a *killer key* — a decisive,
master/skeleton key that opens anything. Attached to `coder`, the whole handle
pictures the person who holds that key: the coder with the answer, the one who can
get into any lock. That is a flattering thing to wear, not a jab at anyone (criterion
5). The odd `ekiling` spelling looks like a real, idiosyncratic handle rather than a
constructed joke, which helps criterion 1 and 4. The repeated `k` sounds and the two
`key` endings give it a rhythmic, slightly lopsided shape that is easy to recall
after one look (criterion 3), and the "killer key" idea lands without explanation
(criterion 2).

## Alternates considered and rejected

- `ekilingkeycoder` — same words, hyphen removed. Still a single token but not the
  registered handle form; also changes the bytes. Rejected.
- `ekiling-key-coder` — second hyphen added. Not the handle. Rejected.
- `killerkey-coder`, `skeletonkey-coder`, `masterkey-coder`, `keycoder` — plainer
  versions of the same pun and easier to parse, but they are not the entrant's real
  handle. Criterion 1 outranks humour, so these are **not enterable** regardless of
  how they might score on the other criteria.

No alternate may be substituted: the criterion-1 handle is fixed, and the judging
task here is presentation of that one name, not invention of a funnier one.
