# One Word, One Username, One Reward

Writes the entrant's own make.fun handle, `ekilingkey-coder`, as the single-word entry.
Run `python3 main.py` to write the exact 16 bytes to `/output/entry.txt`.
Run `python3 main.py --check` to read the file back and report MATCH.
Offline, deterministic, Python 3 standard library only.
See research.md for the handle rationale and the title.txt presentation phrase.
